# طية — دليل التاجر | Tayya merchant guide

Arabic-first documentation with English counterparts for the Tayya Salla theme, prerelease 0.1.0.

Open `index.html`. The site consists of static HTML and CSS and has no runtime dependencies. It can be served by GitHub Pages from the repository root; `.nojekyll` preserves the prepared output.

The guides cover setup, all 22 section types, product-specific sizing and materials, GIF/video/parallax, integrations, updates, troubleshooting and contact details.

Contact: dev.mhnd@gmail.com. Support phone, chat and operating hours have not yet been announced. The theme has not been published or approved by Salla.

Alexandria and Manrope fonts are redistributed under the included SIL Open Font License notices in `assets/fonts/`.
